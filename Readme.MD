## Loja de Trufas - Projeto Integrado

Este projeto foi desenvolvido no âmbito do **módulo de Engenharia de Software e Arquitetura de Sistemas**, com o objetivo de propor, modelar e implementar um sistema para **gestão de vendas e estoque de uma loja de trufas**.  
O projeto integra conceitos de levantamento de requisitos, modelagem UML, arquitetura de software, prototipagem e documentação técnica.

---

##  Funcionalidades
- Cadastro e autenticação de usuários (cliente e administrador).  
- Visualização e seleção de produtos (trufas).  
- Registro de vendas e geração de recibos.  
- Controle de estoque de produtos.  
- Processamento de pagamentos (simulado).  
- Consultas e relatórios de vendas (administrador).

##  Tecnologias Utilizadas
- **Frontend:** React / HTML5 / CSS3  
- **Backend:** Node.js / Express  
- **Banco de Dados:** MySQL ou PostgreSQL  
- **Ferramentas de Modelagem:** Graphviz, UML  
- **Controle de Versão:** Git & GitHub  

---

##  Cronograma de Desenvolvimento (4 semanas)
1. **Semana 1:** Levantamento de requisitos e modelagem inicial.  
2. **Semana 2:** Definição da arquitetura e criação dos diagramas UML.  
3. **Semana 3:** Implementação parcial (cadastro, vendas, estoque).  
4. **Semana 4:** Testes, integração e documentação final.
